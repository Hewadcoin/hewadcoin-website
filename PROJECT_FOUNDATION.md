HEWAD COIN — Project Foundation

Project Identity

- Project Name: HEWAD COIN
- Repository: Hewadcoin/hewadcoin-website
- Project Type: Secure, modular cryptocurrency platform
- Backend: Supabase
- Source Control: GitHub

Core Principles

1. Security first.
2. Protect all user accounts and financial records.
3. Never delete existing user balances or transaction history during updates.
4. Keep all sensitive credentials on the server.
5. Enforce permissions on the server and database.
6. Build modular features that can be enabled or disabled later.
7. Keep a clear audit history of important administrative actions.

Owner Security

- The project owner is the only Super Admin.
- Owner access must be provisioned securely.
- Never grant Owner privileges through public registration.
- Other administrators must have limited permissions.
- Administrators must never be able to promote themselves to Owner.

Financial Data

- Store balances and transactions securely.
- Use a transaction ledger.
- Prevent duplicate financial operations.
- Never trust balance values submitted by the browser.
- Preserve financial history when coin prices or settings change.

Development Rules

- Plan before implementation.
- Review database changes before execution.
- Back up important data before migrations.
- Test security and functionality before public deployment.
- Never publish secrets or private keys in frontend code.

Development Status

- Database schema not yet implemented.
- User interface not yet implemented.
